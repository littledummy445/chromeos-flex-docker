
# Contributing to ChromeOS Flex Docker Emulator

Thank you for your interest in contributing! Whether it's reporting a bug, improving documentation, or suggesting new performance tweaks, contributions are welcome.

## How to Contribute

1. **Fork the Repository**: Click the "Fork" button at the top right of the repository page.
2. **Create a Branch**:
```bash
git checkout -b feature/your-improvement-name

```


3. **Make Your Changes**: Edit documentation, add scripts, or improve container configurations.
4. **Commit Your Changes**:
```bash
git commit -m "Add descriptive message about your changes"

```


5. **Push and Open a Pull Request**: Push your branch to GitHub and open a Pull Request against the main branch.

## Guidelines

* Keep container commands safe and verify hardware acceleration paths (/dev/kvm).
* Document any storage or resource impacts clearly in the README if adding new features.
